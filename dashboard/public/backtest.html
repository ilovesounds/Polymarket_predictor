Run backtest locally

Backtests run in the terminal via backtest/engine.js and print win rate, bankroll curve, and Sharpe to stdout. The live dashboard does not embed results yet — use the commands below from the project root.

Default (15m window) npm run backtest
5-minute window npm run backtest:5m
Custom strategy / bankroll BOT_STRATEGY=deterministic_yes_50 STARTING_BANKROLL=5 npm run backtest

After a run, compare metrics with paper trading on the Bot page or watch live prices on Live.
