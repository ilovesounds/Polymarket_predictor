Overview

This project is a paper-trading bot for Polymarket BTC short-window markets (5-minute and 15-minute “up or down” windows). It streams Binance BTC prices and Polymarket CLOB data, runs signal strategies, and exposes a local dashboard for monitoring and control.

Main components:

  • bot.js — live polling loop (hard-locked to paper mode)
  • dashboard/server.js — HTTP + WebSocket UI on port 3847 by default
  • backtest/engine.js — historical simulation on resolved markets
  • feeds/natsPublisher.js — Node publisher to NATS (optional)
  • rust/feeds-rs — low-latency Rust NATS publisher (optional)
  • signals/ — strategies and edge-case detectors
  • risk/manager.js — Kelly sizing, liquidity gates, circuit breaker
Docs URL when the dashboard is running: http://localhost:3847/docs (or your DASHBOARD_PORT).

Quick start

  1. Clone the repo and install dependencies:
cd polymarket_bot
npm install
cp .env.example .env
  1. Edit .env — for the simplest path, keep NATS_URL=disabled and USE_NATS=false.
  2. Start the dashboard:
npm run dashboard

Open /live at http://localhost:3847/live.

  1. Optional — run dashboard + bot together:
npm run dev

Or start/stop the bot from the Bot page in the UI.

Live paper trading

The bot always runs in paper mode. It polls every 30 seconds, tracks Binance momentum, reads Polymarket midpoints, and simulates entries/exits.

From the dashboard

  1. Run npm run dashboard (or npm run dev).
  2. Open /bot.
  3. Select a strategy, click Start. Logs and bankroll update over WebSocket.
  4. Use Stop to SIGTERM the child process (SIGKILL after 6s if needed).

From the terminal

npm run paper:live
# or with strategy / bankroll:
BOT_STRATEGY=conservative_yes_55 STARTING_BANKROLL=20 npm run paper:live

With ENABLE_DASHBOARD_FEED=true, trade events appear on the Bot page while the dashboard is up.

Trading windows (bot)

  • 5m markets: trades only when 30–270 seconds remain in the window.
  • 15m markets: trades when 60–840 seconds remain.

NATS vs direct feeds

Direct mode (simplest)

npm run dashboard with NATS_URL=disabled or USE_NATS=false:

  • Dashboard opens Binance WS and Polymarket CLOB WS directly in Node.
  • Orderbook via REST poll (~2.5s); midpoint fallback every 5s.
  • No Docker required.

NATS mode

Use when you want decoupled publishers (Node or Rust) and multiple consumers:

  1. npm run nats:up (or ensure NATS on :4222).
  2. Set NATS_URL=nats://127.0.0.1:4222, USE_NATS=true, USE_NATS_FEEDS=true.
  3. Run a publisher: npm run feeds:nats or rust/feeds-rs binary.
  4. Start dashboard: npm run dashboard:nats or full stack npm run dev:nats.

Subjects (see lib/nats/subjects.js): feeds.binance.price, feeds.polymarket.price, feeds.polymarket.orderbook, feeds.polymarket.trades, feeds.polymarket.markets, bot.status, bot.events, bot.control.

If NATS is enabled but no publisher is running, the header may show Polymarket waiting (NATS, no ticks). After NATS_FEED_FALLBACK_MS the dashboard starts direct feeds automatically.

Rust feeds-rs

High-performance alternative to feeds/natsPublisher.js. Publishes the same feeds.* subject family.

cd rust/feeds-rs
cargo build --release
npm run nats:up
export NATS_URL=nats://127.0.0.1:4222
export MARKET_WINDOW=15   # or 5, both
./target/release/feeds-rs

Subscribe for debugging: nats sub 'feeds.>' (requires NATS CLI). Monitoring UI when using project Docker: http://localhost:8222.

Backtest 5m / 15m

The backtest engine loads resolved BTC short-window markets, fetches history (PolyBackTest API with CLOB fallback), and simulates the deterministic YES strategy.

# 15-minute windows (default)
npm run backtest

# 5-minute windows
npm run backtest:5m

# Custom sample size
BACKTEST_WINDOWS=100 npm run backtest:5m

Output includes win rate, P&L, bankroll curve, and Sharpe ratio in the terminal. The Backtest dashboard page lists these commands but does not run the engine in-browser.

MARKET_WINDOW=both uses 15m as the primary backtest window when multiple windows are allowed (see getBacktestWindowMinutes() in backtest/engine.js).

Troubleshooting

Port already in use (3847)

Another process is bound to the dashboard port. Either stop it or set DASHBOARD_PORT=3848 in .env and restart.

NATS / stack overflow or hang on startup

If enabling NATS caused crashes or deep recursion in older setups, use the current defaults:

  • NATS_URL=disabled and USE_NATS=false for npm run dashboard only.
  • NATS_CONNECT_TIMEOUT_MS=8000 so a dead broker does not hang forever.
  • Dashboard falls back to direct feeds when NATS is unavailable or idle.

Polymarket waiting (NATS, no ticks)

Start npm run feeds:nats or feeds-rs, or switch to direct mode (USE_NATS_FEEDS=false).

WebSocket disconnected

Confirm the dashboard is running and you are using the same port in the browser. Check firewall/VPN blocking localhost WS.

No active BTC 5m/15m markets

Markets expire quickly. Try both in the header selector or wait for the next window. Gamma API rate limits: adjust MARKET_SEARCH_PAGES if needed.

Backtest: PolyBackTest unavailable

The engine falls back to CLOB trade reconstruction automatically; runs may be slower.

Bot will not start (409)

Bot already running or still stopping — use Stop on the Bot page or kill the child PID shown in status.
